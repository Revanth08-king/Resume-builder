1. Introduction

1.1 Project Overview

Folio is an advanced, client-side, privacy-preserving resume builder designed to help students, recent graduates, and software engineers craft recruiter-ready, ATS-compliant resumes with instant live visual feedback. Unlike bloated commercial resume builders that gate essential features behind paywalls or sell user data, Folio operates entirely in the browser with zero external backend dependencies.

1.2 Purpose and Objectives

  • Fixed-Screen Live Preview: Keep an authentic, physical A4 sheet (210 × 297 mm) pinned permanently on the screen while the form editor scrolls independently.
  • In-Preview Direct Click-to-Edit: Enable users to click directly on any text on the resume paper to edit it in place with seamless two-way synchronization back to the sidebar forms.
  • Recruiter-Readiness & ATS Coach: Provide instant heuristic evaluations (word counts, action verbs, quantifiable metrics, contact links) to ensure maximum recruiter engagement.
  • Instant Public Sharing: Encode the entire resume data structure into a shareable URL hash with a generated mobile QR code, enabling seamless review by mentors and peers.
  • Zero-Cost Vector PDF Generation: Utilize native browser print engines with tailored CSS media queries to produce crisp, single-page vector PDFs without paid server rendering tools.

2. Project Overview

2.1 Problem Statement

Many students and job seekers face significant hurdles with resume creation:

  • Commercial platforms lock standard PDF downloads behind paid subscriptions.
  • Applicant information is frequently stored on insecure servers or sold to third-party recruiters.
  • Unsynchronized layouts cause previews to vanish off-screen when users edit longer sections.
  • Inconsistent printer drivers result in single-line page overflows that immediately disqualify applicants.

2.2 Solution Overview

Folio solves these issues by delivering a zero-dependency, private web application engineered using modern HTML5, CSS3, and ES6+ JavaScript. All applicant information stays locked within the user's browser sandbox, offering real-time ATS scoring, 7 recruiter-tested templates, and an authentic A4 physical drafting canvas.

3. System Architecture

3.1 High-Level Architecture

Folio employs a reactive client-side Model-View-Controller (MVC) architecture running within the browser. The data store (Model) resides in JavaScript memory and localStorage, the View consists of semantic HTML5 templates, and the Controller handles real-time synchronization, ATS heuristics, and printing.

4. Features and Functionality

4.1 Fixed A4 Resume Preview Stage

The right preview panel stays completely fixed on the screen while the form editor scrolls independently on the left. The paper is styled to exact ISO 216 dimensions (794px × 1123px at 96 DPI), providing a faithful visual match to a printed physical sheet.

4.2 In-Preview Direct Click-to-Edit & Two-Way Sync

Users can click and edit any header, contact element, summary text, or bullet point directly on the resume sheet. Changes reflect in real time across the sidebar inputs, ATS scoring bar, and localStorage without causing cursor/caret jumps.

4.3 Bidirectional Scroll Synchronization & Focus Glow

As the user scrolls through the form editor, a scroll-spy engine identifies the active section card and auto-scrolls the A4 sheet to center that section, highlighting it with an accent glow (.is-scrolling-active).

4.4 Section Visibility Toggles

Interactive chips in the stage toolbar allow users to instantly show or hide any resume section (Summary, Education, Experience, Projects, Skills, Awards) with a single click.
