Folio – Privacy-First ATS Resume Builder & Real-Time Document Engine

A client-side web application designed to help students and job seekers create, evaluate, and export recruiter-ready resumes. Features zero-backend architecture, deterministic ATS scoring, URL-encoded state sharing, and print-accurate vector PDF rendering.

1. Problem Statement & Objectives

Most commercial resume builders (e.g., Canva, Novoresume, Zety) suffer from severe limitations that disadvantage college students:

  • Paywalled Downloads: Users spend hours tailoring their content, only to be blocked by a mandatory credit-card subscription before exporting.
  • Privacy & Data Harvesting: Personal Identifiable Information (phone numbers, full names, locations) is stored on remote commercial servers.
  • ATS Incompatibility: Visually ornate design tools generate un-parseable graphics, irregular font embeddings, and non-standard layouts that fail modern Applicant Tracking Systems (ATS).

Project Objectives:

  1. Deliver a 100% free, browser-native resume studio with zero login friction.
  2. Implement a deterministic 7-point ATS scoring engine that gives instant heuristic feedback on summary length, quantifiable numbers in bullets, and contact integrity.
  3. Provide instant public sharing by serializing state into URI hash permalinks without requiring any backend database.
  4. Ensure pixel-perfect vector A4 printing using CSS Paged Media module.

2. System Architecture & Data Pipeline

The system follows an Event-Driven Reactive Architecture running entirely within the browser's JavaScript V8/SpiderMonkey runtime:

+-----------------------------------------------------------------------------------+ | CLIENT BROWSER RUNTIME | +-----------------------------------------------------------------------------------+ | | | [ User Input / Form Controls ] <-----> [ Central State Store (S) ] | | | | | +------------------------------------------+---------------------+ | | | | | | | v v v | | [ DOM Renderer Engine ] [ ATS Quality Coach ] [ Local Storage]| | | | | | | +----------------+ +---------------------+ | | v | | [ Live A4 Preview Stage ] | | | | | +------------------+------------------+ | | | | | | v v | | [ Print CSS / Vector PDF ] [ URI Hash Serializer ] | | (@media print engine) (#resume=base64(JSON)) | | | | | v | | [ Public Shareable Link ] | +-----------------------------------------------------------------------------------+

Key Architectural Modules:

⚡

Reactive State Manager

Maintains unified state across template style, active accent colors, font stacks, and section arrays. Synchronizes automatically to HTML5 LocalStorage on each keystroke.

🛡️

Deterministic ATS Heuristic

Evaluates resume strength across seven industry standards, providing real-time suggestions, metric alerts, and copy-pasteable polished draft copy.

🔗

URI Hash State Serializer

Encodes the resume JSON object into URL-safe Base64 strings. Enables instant peer-to-peer sharing with zero database reliance.

🖨️

Vector Print Engine

Utilizes CSS Paged Media standards (@page { size: A4; margin: 12mm; }) to yield crisp, high-resolution vector PDFs via native print dialogs.

3. ATS Scoring Matrix & Evaluation Logic

The built-in coach analyzes the candidate's draft against seven empirical resume quality checks:

Check Name Validation Rule Rationale
Contact Integrity Full Name ≥ 2 words, Valid RFC 5322 Email, Verified portfolio URL Ensures recruiters can contact candidates and verify their code or work samples.
Summary Length Word count between 20 and 60 words Short enough for a 6-second recruiter skim, but detailed enough to convey core specialization.
Education Entry School name, degree, and date range defined Satisfies baseline academic verification criteria for university grads.
Substantial Experience ≥ 2 roles or engineering projects Demonstrates applied competence beyond coursework.
Quantifiable Proof At least one bullet contains numbers (%, $, count, time) Proves tangible business or technical results (e.g. "Cut latency by 40%").
Bullet Conciseness All bullet items < 25 words Prevents wall-of-text fatigue in human scanning.
Skills Inventory ≥ 5 distinct technical or soft skills Provides keywords for automated Applicant Tracking System indexing.

4. Technical Stack & Implementation Details

  • Markup: Semantic HTML5 (Custom Details/Summary accordions, ARIA live-regions, Accessible Form Controls).
  • Styling: CSS3 Custom Properties (CSS variables), CSS Flexbox & Grid layouts, Backdrop Filter, Print Media Rules.
  • Typography: Google Fonts (Instrument Sans, Bricolage Grotesque, Source Serif 4, Roboto, Inter, Poppins).
  • Scripting: Vanilla JavaScript ES6+ (Zero external npm libraries or bloated frameworks).
  • Storage & I/O:
    • localStorage for instant persistent drafts.
    • Blob & URL.createObjectURL for instant JSON backup exports.
    • FileReader API for client-side JSON file restoration.
    • Navigator.clipboard API for one-click permalink sharing.
